# Shared disclosure and search

`components/web/disclosure.html`, `styles/disclosure.css` and `scripts/disclosure.js` own indexed native disclosure rows, Search-to-X artwork, and the reusable search control. They do not own consumer selection, search data, result rendering, or locale/theme preferences.

`indexed_item(number,label,opened=false)` accepts trusted Jinja caller content. Native details remain independently expandable when unnamed; the optional `group` argument uses native exclusive selection. For an enhanced exclusive group that must retain its selection, place its same-name rows (one initially open) directly inside a container marked `data-ui-disclosure-required`. The shared controller prevents closing the active row on repeated activation; selecting another row still uses native group semantics. Without JavaScript, native disclosure remains available and all rows may be closed. `search_control(id,label,close_label,placeholder,color_token='--ui-color-accent')` receives static bilingual message references and a canonical color token. It emits bubbling `ui:searchchange` with `{query}` on input and when explicitly closed (Escape or toggle). The control owns expansion, focus, clear and accessible labels; consumers filter their own data without reinitializing on locale change. Search is unavailable without JavaScript, while native details and content remain accessible.

`toggle_art()` and `UI.disclosure.toggleArt(art,active,animate=true,colorToken='--ui-color-accent')` expose the shared artwork independently of the search field. `UI.disclosure.matches(text,query)` performs accent/case-insensitive all-words matching; `search_text` in presentation prepares bilingual metadata. The asset service owns loading and caching. About uses the opt-in required-selection group; report disclosures and unmarked groups retain their existing behavior.

See [report sections](report-sections.md) for artifact-specific behavior and `tests/test_report_sections.py` for shared and consumer regression coverage.

Indexed consumers may set `--ui-disclosure-duration` on their container to synchronize Search-to-X playback with their layout transition; the default remains `--ui-duration-link`. Required selection and independent report disclosure behavior are unchanged.
