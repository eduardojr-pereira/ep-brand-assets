# EP Analytical Colour System

Scientific Colour Maps 9.0.0 — Fabio Crameri, MIT. DOI: https://doi.org/10.5281/zenodo.24343380. Method: https://doi.org/10.1038/s41467-020-19160-7.

Classify the colour-encoded variable first: independent categories → categorical; ordered magnitude → sequential; meaningful central reference → diverging; distinct ordered domains → multi-sequential; periodic values → cyclic. Choose continuous or discrete representation where appropriate. Primary palettes: EP Muted Pastel, Nuuk, Vik, Fes, VikO. Alternatives: adapted LipariS, Lipari, Delphi; Ston for dark-centred divergence. Preserve official RGB samples and document limits, direction and midpoint. Do not switch scientific scales solely because the interface theme changes.

Custom categorical palettes require redundant visual encoding (dash, symbol, pattern or text); contrast against background alone does not establish colour-vision accessibility. LipariS adaptation is not an official Crameri palette. Use the same series roles across comparable figures. No project-specific hex codes for analytical series.

Bike Sharing uses Muted Pastel for categorical and single-colour charts, sign-coded residual bars, Vik for correlations (-1 to +1), Nuuk for hourly intensity. Data and model calculations are unchanged.
