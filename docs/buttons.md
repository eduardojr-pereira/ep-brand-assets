# Buttons & Actions

Load `styles/foundations.css`, `styles/motion-tokens.css`, `styles/links.css`, then `styles/buttons.css`. Load `scripts/buttons.js` with `defer`. Import `components/web/buttons.html` with HTML autoescaping enabled. These are shared Jinja macros, not an independent builder or page.

- `radial_link(label, href)` supplies Learn More and equivalent actions. The arrow macro and diagonal movement classes are imported from Links & Navigation. The radial surface uses the common 550ms outCirc fill; it inverts black/white, with no duplicate arrow or underline rules.
- `carousel_arrow(label, direction='next', disabled=false)` supplies Previous/Next with horizontal SVG arrows, a circular border and the same radial surface, without magnetism. The actual carousel controller owns slide selection and disabled state; read `data-ep-carousel-action` for the action. Default dimensions are 45px desktop, 40px at <=720px and 36px at <=420px, with contextual `--ep-carousel-size` available. Preserve the approved section geometry when composing the page.
- `orbit_link(id, label, ring_label, href, variant='hero')` supplies Selected Projects and Say Hello from one component. Pass unique safe IDs, destination and localized accessible/visible labels; use the `cta` variant for Say Hello. Hero width is `min(10.5vw, 11.25cqw, 18svh, 156px)` in the page's inline-size container; mobile uses `clamp(90px, 17vw, 120px)`. CTA uses `clamp(98px, 9.3vw, 138px)` and 100px mobile, based on the settled Style Guide contract. Ring uses Inter, 20s rotation and the 3.37s arrow cycle. Shared radial fill is 98/144 of the orbit diameter. Pointer displacement is 30% of the offset, capped at 12px per axis; disabled on coarse pointers or reduced motion. Continuous motion pauses when offscreen or the document is hidden when JS is available. Keyboard focus activates the radial effect; native links remain navigable without JS. `EPActions.setOrbitLabel(element, accessibleLabel, ringLabel)` updates the ring and accessible name. Page composition owns the surrounding hero/CTA content and video reveal.
- `send_action(label, sent_label, feedback, pending_label='', error_feedback='')` renders a native submit button, reserved label/status geometry and accessible feedback. `EPActions.setSendState(wrapper, 'pending')` disables repeat submission; `'error'` permits retry; `'idle'` resets. Only after the real transport confirms acceptance may the form controller call `EPActions.setSendState(wrapper, 'success', {confirmed: true})`. This explicit flag is an integration contract, not a network verification mechanism; this library performs no network request, intercepts no native submit and does not simulate success on click. The success state uses the existing semantic success color, shows a check instead of the arrow and reveals the supplied live-region copy. `EPActions.setSendLabels(wrapper, {idle, pending, success, successFeedback, errorFeedback})` updates localized labels and feedback without resetting the state. The transport provider, validation and final error/pending copy remain the Contact Form's responsibility. Success text: “Message sent” / “Mensagem enviada”; feedback: “We'll be in touch soon.” / “Entraremos em contato em breve.”

Contextual properties include `--ep-action-padding`, `--ep-action-gap`, `--ep-carousel-size`, `--ep-orbit-size`, `--ep-action-ink` and `--ep-action-on-ink`. Black/white radial ink values apply to the approved monochrome action variants; no changes to Foundations. Contact social icons will use this radial surface when the shared Lottie assets are integrated, not a second fill implementation. Pill sizing is initially 12px 22px from the settled Style Guide; exact placements and geometry must be validated against the approved sections during integration.

Run `python3 tests/test_buttons.py` with Jinja2, Playwright and Chromium (or set `EP_TEST_BROWSER`). The tests exercise the real shared templates and prior motion/link CSS in an isolated browser document. They do not create another visual study or send a real message. Font loading, actual carousel content, provider response, full i18n controller, final layout and GitHub Pages delivery remain integrated acceptance tests.
