# Cards & Interactive Components

Load the shared styles and scripts in the order declared in `config/ui.json`. Use the canonical Jinja macros with HTML autoescaping enabled. No separate page builder is defined here.

## Contracts

- Graphical badges are rendered by the shared [badge library](badges.md).
- `project_card(project)` accepts `title`, `description`, `collection` (`selected` or `learning`), `collection_label`, `areas` (space-free stable keys), `topics`, `badges`, optional `search` keywords, and `links` (`label`, `href`, `primary`). Supply only approved destinations and data. A primary link calls the diagonal macro from Navigation; other links use its underline primitive. No card-specific text/arrow animations.
- `catalog(id, projects, areas)` wraps the cards in the approved 3/2/1-column grid (1050px and 650px breakpoints). `areas` contains `{value,label}`. Collection and area selectors are the canonical Navigation filters. Search matches a generated bilingual index (title, description, collection, topics, badge labels, links and supplied keywords), without case/accent sensitivity; all query words and both filters must match. Clear, count and empty state are supplied; no projects are created or published by this component. Shared labels and count pluralization come from `config/translations.json`; consumers pass `message(key)` references for project content. Search metadata is generated by `tools/presentation.py` from the same shared/local dictionaries. A locale change translates the count and interface without changing matching projects, reselection or clearing the query.
- `selected_projects(projects)` accepts `title`, `subtitle` (optional), `description`, `badges`, `href`, `frames` (possibly empty), and `metrics` (possibly empty, `{value,label}`). Supply only projects approved as selected; the test fixture includes two synthetic slides to exercise navigation. Native horizontal scrolling/snap, keyboard arrows/Home/End and mouse drag are supported. Previous/next use the canonical Buttons macro; one item disables both controls. The evidence carousel advances using `--ui-duration-evidence-cycle` (4500ms), has manual dots and pause, suspends while offscreen, hidden, hovered, focused, inactive or reduced-motion, and uses supplied `{src,alt,caption}` with optional `light` and `dark` images. The asset service applies image variants; the evidence controller owns frame and playback state only. Counts, metrics and figures are supplied by the consumer and are not generated from test data. The component does not impose a fixed viewport height; the page composition will reconcile viewport geometry with the approved study and actual sticky header. Entry animation reuses `ui-motion-enter`; contextual timing follows the reference, but the exact clipping/reveal and frame crossfade choreography remain to be verified in the integrated Selected Projects section.
- `marquee(email, href)` renders the two approved opposite lanes, one actual contact anchor and one pause button. Uses the shared diagonal SVG, monochrome action colors and outCirc transition; the lens has a decorative synchronized copy, with no interactive duplicates. The two lanes move at 66px/s and 65% of that pace (42px/s base below 640px); hover pauses both in place and rotates the arrows toward the contact destination. The cursor is hidden only with a fine pointer and a live lens; reduced motion renders a static invitation, and touch keeps the normal link. Offscreen, inactive tab and explicit pause suspend movement. Initial lens diameter 112px reflects the study's default, not a separately approved dimension. Change `--ui-lens-size` (radius) contextually if necessary. `UI.i18n` updates the original unit and accessible labels before emitting `ui:languagechange`; the controller reflows decorative copies without independent translation bindings. Use the email from brand configuration, not the fixture address. There are no experimental mask alternatives or study controls.

Card surfaces, catalogue grids and Selected Projects metrics reuse [analytical primitives](analytical.md). Hover and carousel interactions remain contextual to this component. Project title, subtitle, description and category typography use [editorial primitives](editorial.md). The report introduction consumes the same badge renderer. Contact Form transport and About integration remain pending; the [report sections](report-sections.md) provide the Artifact Explorer and shared search/disclosure contract; the [shell](shell.md) is available. No report tabs or reference slider are required by the current layout contract.

## Verification

Run `python3 tests/test_interactive.py` with Jinja2, Playwright and Chromium (override browser path via `UI_TEST_BROWSER`). Tests compose the actual shared macros and CSS/JS from the first four lots; synthetic figures isolate behavior; canonical font loading is required by the shared test fixture. The suite checks both themes, combined filters and reset, primary link text/arrow displacement, previous/next and manual evidence, monochrome lens synchronization, pause/resume, mobile/reduced-motion and static fallback. It does not certify actual project data, responsive page composition, full consumer translation coverage or Pages publication.
