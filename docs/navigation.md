# Links & Navigation

Load the shared styles and scripts in the order declared in `config/ui.json`. Use the canonical Jinja macros with HTML autoescaping enabled. No separate page builder is defined here.

- `diagonal(label, href, accent=true, spread=false, underline=true)` supplies the shared diagonal arrow, directional underline and simultaneous text displacement. Cards, project links and Knowledge Base links use this same primitive. Radial buttons reuse its arrow and movement classes; see [buttons](buttons.md).
- `text_link(label, href, muted=true)` is the ordinary shared underlined link without an arrow.
- `nav_link(label, href, current=false, muted=true)` and `filter_button(label, value, selected=false)` use a regular/semibold two-layer label with one accessible name and stable width. Privacy/Terms can use `nav_link` with contextual sizing. Use `message(key)` references for translatable labels; both layers and return links bind to the same key. The dropdown selection mirrors the key of the selected option through `UI.i18n.bindFrom`, never a local translation dictionary.
- `editorial(label, description, href)` is a call-block macro: pass the decorative icon/Lottie host in the caller. Title and description remain separate and move as one aligned block, with the description below the title. The shared row has a stable bottom divider and accent underline. Footer-specific sizing, spacing, icons and optical scales belong to the Footer component.
- `return_link(label, href, vertical=false)` performs horizontal replacement (Back to Portfolio) or vertical replacement with a persistent underline (Back to Top). Include the directional glyph in the localized label. Link destinations and placement belong to consumers.
- `disclosure(label, filter_name='', align_end=false, default_value='all')` is a call-block macro: pass `menu_link` for GitHub links, `area_option` for area filtering, and an optional `<hr class="ui-dropdown__divider">`. Native details/summary supplies click and keyboard disclosure, while the shared controller closes other menus, outside clicks and Escape. GitHub items have text and arrow movement without an internal underline, as in the approved design. End-align menus near the right viewport edge.
- For a filter group outside a disclosure, wrap `filter_button` items in an element with `data-ui-filter="collection"` (or another stable name). Set one initial `aria-pressed="true"` per group. The controller updates selection and emits bubbling `ui:filterchange` with `{name, value}`. Consumers filter actual project data, not the navigation library. `UI.navigation.select(group, value, false)` sets a selection without notifying. A disclosure also updates its summary and persistent filtered state.
- Area check uses the original `assets/animations/lottie-checkbox-v1-orange.json` unchanged. `UI.assets` loads and caches the pinned player and source, mounts the SVG and recolors a copy using the accent token. Navigation owns the selected state and animation segments (0–44 / 85–119 over the shared link duration), not the player lifecycle. On theme change the shared loader remounts and the selected frame is restored. Static fallback remains visible on unavailable player/assets; reduced motion snaps to the correct frame. The actual player is exercised by the local regression suite.
- For section navigation, mark each group `data-ui-scroll-nav` and targets `data-ui-section` with unique IDs. Set `--ui-sticky-offset` at the page/header level. Opt into smooth anchor scrolling with `data-ui-smooth-scroll` on the document root. Selection follows the section crossing the sticky offset, with click-lock during anchor movement. Reduced motion disables smooth scrolling. The same controller recalculates on locale/theme changes and body/section resize. Header-specific compact layout and sizing belong to the [Header component](shell.md). Do not add another scroll spy.

Contextual CSS properties include `--ui-link-gap`, `--ui-link-padding`, `--ui-link-arrow-size`, `--ui-link-rule-size`, `--ui-link-rule-offset`, and `--ui-link-color`. Only layout and semantic variants should override these. Text movement (8px), arrow movement and durations come from `styles/motion.css`. No local hover or underline implementations in consuming pages.

Run `python3 tests/test_navigation.py` with Jinja2, Playwright and a Chromium-compatible browser installed. Tests render the canonical macros in a fixture, not a new design preview. The local suite exercises the actual Lottie runtime and fonts; integrated visual fidelity and remote delivery remain pending.

Header consumes the same scroll-navigation controller and disclosure macros. `nav_link(..., menu_arrow=true)` includes the canonical diagonal arrow for compact placement; the Header selects existing link classes based on layout, without duplicating the link or its effects. `disclosure(..., chevron=true)` is optional for GitHub. Nested link activation closes enclosing disclosures. See [Header and Footer](shell.md).

An unlinked transition area may declare `data-ui-nav-neutral`; the same strict majority-of-usable-viewport rule as the footer clears the active section. `ui-underline[data-ui-focus-within]` reuses the underline primitive for a focusable descendant.
